Bundled SVG marks for PaperStreet's fixed stock universe. Most marks are sourced from the Simple Icons project (https://github.com/simple-icons/simple-icons), including Microsoft and Amazon from release 11.0.0 before their removal. Disney uses Tabler Icons' brand-disney outline (https://github.com/tabler/tabler-icons). Microsoft's colored four-square mark and SPY's ticker/price-chart badge are small local SVGs. All files load from the Activity bundle; no third party image services, trackers or runtime network requests are required. Brand marks remain the property of their respective owners.
